Python setup

For the LT-FH exercise. You need Python 3.12 or 3.13, Git, NumPy and SciPy. ltpred is not on PyPI. Use the python.org steps for your system, or the Anaconda steps, which are the same on both. Numba only speeds ltpred up. Matplotlib is only for the worked answers. No compiler, no R, and no data files. Open a new terminal after each installer. The prompt must show (ltpred-class) before the ltpred commands.

macOS

Install Git, then Python from python.org. Use that Python. If pip reports a certificate error, run Install Certificates.command in /Applications/Python 3.13/.

xcode-select --install
python3 -m venv ~/ltpred-class
source ~/ltpred-class/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy scipy numba jupyter

Windows

Install Git from git-scm.com/download/win. Install Python from python.org and tick Add python.exe to PATH. If python opens the Microsoft Store, use py. In PowerShell:

py -3.13 -m venv $HOME\ltpred-class
$HOME\ltpred-class\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install numpy scipy numba jupyter

If activation is blocked, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once and activate again.

Anaconda

Skip the two sections above. Install Anaconda from anaconda.com/download. Miniconda is the same commands with a smaller download. On Windows, open Anaconda Prompt. On macOS, open Terminal.

conda create -n ltpred-class -c conda-forge python=3.13 numpy scipy numba jupyter matplotlib git -y
conda activate ltpred-class

ltpred

With (ltpred-class) active:

git clone https://github.com/bvilhjal/ltpred.git
cd ltpred
python -m pip install -e ".[fast]"
python -m jupyter lab

If Numba did not install, use python -m pip install -e . instead. On the python.org path, the worked answers also need python -m pip install matplotlib.

Open the exercise from Jupyter and run the setup cell. It should print ltpred 0.7.0 or newer. Part 0 takes about a minute and needs under 1 GB of memory.
