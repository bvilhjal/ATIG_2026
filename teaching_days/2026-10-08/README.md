# 8 October 2026

MR practical using BMI and coronary heart disease GWAS results, followed by a short
simulation of pleiotropy. Seven questions, about an hour. All code is given; students
explore the data, interpret the results and change the settings marked `# TRY`.

[Open the exercise in Google Colab](https://colab.research.google.com/github/bvilhjal/ATIG_2026/blob/main/teaching_days/2026-10-08/MR/MR_practical.ipynb)
(nothing to install; choose *File → Save a copy in Drive*).
